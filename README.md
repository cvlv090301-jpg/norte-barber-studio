OBJETIVO DEL SITIO
El objetivo principal es convertir visitantes en clientes.
El visitante debe poder entender rápidamente:
Qué ofrece el negocio.
Por qué debería elegirlo.
Cuánto cuestan sus servicios.
Dónde está ubicado.
Cómo puede contactar o reservar.
El sitio debe sentirse como una página profesional de un negocio establecido, no como una plantilla genérica generada por IA.
ESTRUCTURA
Crea las siguientes secciones:
1. HERO
Mostrar inmediatamente:
Nombre del negocio.
Una frase corta y específica que comunique su propuesta de valor.
Una fotografía visualmente atractiva relacionada con el negocio.
Botón principal: "RESERVAR CITA" o "CONTACTAR POR WHATSAPP".
Botón secundario: "VER SERVICIOS".
El CTA principal debe ser claramente visible.
2. PRESENTACIÓN
Una sección breve que explique quién es el negocio, qué ofrece y qué tipo de experiencia proporciona.
Evita textos genéricos, exagerados o frases vacías.
3. SERVICIOS Y PRECIOS
Mostrar los servicios en tarjetas claras.
Cada tarjeta debe incluir:
Nombre.
Descripción breve.
Precio.
Duración, si está disponible.
Los precios deben ser fáciles de encontrar.
4. BENEFICIOS / DIFERENCIADORES
Mostrar entre 3 y 5 razones concretas para elegir el negocio.
Utiliza únicamente características proporcionadas en los datos del negocio.
NO inventes certificaciones, años de experiencia, productos, premios, especialistas, sucursales ni servicios que no hayan sido proporcionados.
5. GALERÍA
Crear una galería visual para mostrar trabajos, productos o instalaciones.
Si todavía no existen fotografías reales, utiliza placeholders claramente identificables que posteriormente puedan sustituirse fácilmente.
No inventes fotografías que representen resultados reales del negocio.
6. PROMOCIÓN
Si existe una promoción actual, mostrarla en una sección destacada.
Si no existe promoción, omitir esta sección.
7. UBICACIÓN
Mostrar:
Dirección.
Horario.
Botón "Cómo llegar".
Mapa o integración de mapas cuando sea posible.
8. CONTACTO / RESERVACIÓN
Crear una sección final con una llamada clara a la acción.
Ejemplo:
"¿Listo para reservar?"
Botón principal:
"RESERVAR CITA"
Si el contacto es WhatsApp, el botón debe abrir una conversación de WhatsApp con un mensaje inicial apropiado.
9. FOOTER
Incluir:
Nombre del negocio.
Ciudad.
WhatsApp/teléfono.
Instagram.
Facebook, si existe.
Horarios.
Aviso de derechos reservados.
DISEÑO
El diseño debe ser:
moderno;
profesional;
limpio;
visualmente atractivo;
coherente con la identidad del negocio;
enfocado en conversión.
No utilizar una estética genérica de "sitio creado por IA".
Utilizar una jerarquía visual clara.
Los botones deben ser suficientemente grandes para tocarse cómodamente desde un teléfono.
Utilizar espacios en blanco adecuados y evitar saturar la página con texto.
Las fotografías deben tener protagonismo.
EXPERIENCIA MÓVIL
Diseña primero pensando en teléfonos.
La versión móvil debe:
tener navegación sencilla;
mostrar claramente el CTA principal;
permitir contactar por WhatsApp fácilmente;
mantener precios y servicios legibles;
evitar textos diminutos;
evitar elementos que se salgan de la pantalla;
mantener imágenes correctamente recortadas;
cargar visualmente de forma limpia.
Agregar un botón flotante de WhatsApp cuando WhatsApp sea el principal medio de contacto.
SEO LOCAL BÁSICO
Optimiza el sitio para búsquedas relacionadas con:
[NOMBRE DEL NEGOCIO]
[TIPO DE NEGOCIO]
[CIUDAD]
[COLONIA / ZONA]
Utiliza estos términos de manera natural en títulos, encabezados y texto.
Crear:
title tag;
meta description;
headings correctamente estructurados;
información de contacto consistente.
No utilizar keyword stuffing.
REGLAS IMPORTANTES
NO inventes información del negocio.
NO inventes reseñas de clientes.
NO inventes fotografías de clientes o trabajos reales.
NO inventes premios, certificaciones, experiencia o estadísticas.
NO agregues servicios que no estén en los datos proporcionados.
Si falta información, utiliza un placeholder claramente identificable o elimina esa sección.
El resultado debe parecer una página real lista para personalizar y entregar a un cliente.
Prioriza conversión, claridad, confianza y experiencia móvil por encima de animaciones innecesarias.
Antes de finalizar, revisa toda la página y asegúrate de que todos los botones y enlaces tengan una función clara y que no existan textos de ejemplo o información ficticia visibles para el cliente.
